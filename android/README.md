# 大肥鱼 安卓版

悬浮球 + 喊“大肥鱼”开始通话。

- 悬浮球：点一下打开聊天；**长按**弹出菜单（通话、日记、记忆、设置、暂停监听、球大小、退出）；按住拖动。
- 唤醒词（大肥鱼 / 肥鱼 / 女儿）在手机本地识别，监听时不联网、不消耗模型额度；听到后才打开通话界面。
- 开机自启动：开机后自动拉起悬浮球和监听。

## 打包
把本压缩包里的 `android` 和 `.github` 文件夹上传到你放网页的仓库根目录，Actions 里运行“打包安卓版”，
完成后在 Releases 里下载 `app-debug.apk` 安装（需允许“安装未知来源应用”）。

## 第一次使用
打开 App，按页面上的 1~4 步完成授权，选好唤醒词，点“启动悬浮球和语音唤醒”，再点“打开聊天”，在设置里登录账号。

## 已知限制
- 安卓 14/15 对“后台开麦克风”有限制：开机后若监听没起来，点一下悬浮球再退出聊天即可恢复。
- 国产手机必须手动允许“自启动 / 后台弹出界面 / 锁屏后台运行”，否则系统会杀掉后台或拦截弹出通话界面。
- 手机会一直显示“麦克风正在使用”的小圆点，这是系统的隐私提示，正常现象。
